## 🖥️ 로컬 개발 환경

1. **의존성 설치**
   ```bash
   npm install
   ```
2. **환경변수 설정**
   - `.env` 파일에 환경변수 입력
3. **개발 서버 실행**
   ```bash
   npm run dev
   ```
